How this works

Each completed course from the Student Transcript tab is mapped to one or more Program Learning Outcomes (PLOs). A course's contribution to a PLO is derived from the student's grade point in that course (Grade Point ÷ 4.00 × 100%). Attainment for a PLO is the average of all mapped, completed courses. Threshold: ≥70% Attained, 60–69% Partially Attained, <60% Not Attained — edit the PLOs and course mapping below to match DSU's official program document.

How this works

Each CLO in the Course Outline tab carries a Mapped PLO tag. This tab groups CLOs by that tag and, for every student entered in the Student Data tab, averages their CLO-level attainment (from actual marks) across all CLOs sharing the same PLO tag. This shows PLO attainment per individual student, alongside the course-level marks already used elsewhere in the app.
